1. ZIP을 압축 해제합니다.
2. README.md를 브라우저/편집기로 읽거나 docs/student_guide.docx를 엽니다.
3. 자기 GitHub 계정에 README가 있는 새 저장소를 만듭니다.
4. 압축 해제한 폴더의 내용물을 저장소 루트에 올립니다. ZIP 파일만 올리지 않습니다.
5. .devcontainer/devcontainer.json이 GitHub에 있는지 확인합니다.
6. 자기 저장소의 Code > Codespaces > Create codespace on main.
7. 터미널에서 bash scripts/doctor.sh 다음 bash scripts/start.sh
8. 실습을 마치면 bash scripts/stop.sh 후 github.com/codespaces에서 Stop.
